# Security and privacy reports

For a credential exposure, personal data, malicious link or other sensitive issue in this repository, use [GitHub's private vulnerability reporting](https://github.com/ravisingh11/agentbay-ultimate-list/security/advisories/new) when available, or email the maintainer at [hello@agentbay.io](mailto:hello@agentbay.io) with the subject “AgentBay repository security report”. Include the affected file or record ID, a minimal reproduction, and the impact. Do not include active credentials, private notes or unnecessary personal information, and do not post sensitive reports in a public issue.

For a vulnerability in a listed third-party project, report it to that project's maintainers using its published security policy. A listing and an Official source label are not a security assessment of that project.

For ordinary broken links, stale metadata and categorization errors, open a [catalogue correction issue](https://github.com/ravisingh11/agentbay-ultimate-list/issues/new/choose).

Maintainers investigate reports, remove exposed material where appropriate, review relevant Git history, and communicate fixes without republishing sensitive details. Response times depend on maintainer availability; no service-level commitment is implied.

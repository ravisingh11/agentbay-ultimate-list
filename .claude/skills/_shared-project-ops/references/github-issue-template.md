# GitHub Issue Template

Use this template for confirmed findings only.

```md
[FINDING-ID][type][severity] Short title

Summary
- Finding: [one sentence]
- Surface: [subsystem]
- Severity: [severity]

Evidence
- [repo proof]
- [repro or failing command]

Impact
- [why this matters]

Fix plan
- [smallest safe fix]

Verification
- [test or validation plan]
```

Search by finding ID before creating a new issue. Reuse and update an existing issue when possible.
